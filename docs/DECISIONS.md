# Registro de decisiones

## Decisiones confirmadas para la base del proyecto
- Nombre del producto: **LIDA**.
- Dirección visual: futurista premium.
- Paleta: negro y verde neón.
- Superficies: paneles oscuros translúcidos, bordes verdes discretos y brillo sutil.
- La fase actual prioriza crear archivos de repositorio; no reabrir las propuestas visuales ya aprobadas.
- Se conserva el alcance de navegación: Chats, Estados, LIDA Play, Reels, Perfil y LIDA AI.
- El diseño se prepara como PWA con intención de publicarse en GitHub Pages.
- No se deben afirmar capacidades de backend, mensajería segura o IA real hasta implementarlas.

## Pendientes que requieren decisión técnica posterior
- Backend, proveedor de identidad y base de datos.
- Protocolo de mensajería y modelo de entrega.
- Cifrado de extremo a extremo, si será una promesa del producto.
- Proveedor de IA, uso de memoria y búsqueda web.
- Políticas de contenido, moderación y almacenamiento.
- Logo maestro original y recursos de marca finales.
